# Green Soft Clay main-menu icons — ImageGen prompts

The five production PNG assets were rendered with built-in ImageGen. The approved design system is named **Balkan Clay Tile**.

## Shared locked art direction

- transparent square PNG;
- thick rounded-square dark forest-green matte-clay tile;
- straight architectural inset frame;
- one uninterrupted terracotta roofline/cap near the top;
- warm-ivory functional pictogram;
- two low muted-sage hills along the bottom;
- almost front-facing camera, soft upper-left studio light and lower-right shadow;
- no text, numbers, metallic/glossy finish, Easter palette, organic medallion or carved relief.

## Daily Challenge — master prompt

Create a transparent PNG mobile-game Daily Challenge icon and master style for a distinctive five-icon Green Theme family called Balkan Clay Tile. Make one thick dark-forest-green clay tile with softly rounded square corners and a precise straight-edged inset frame, like a miniature Balkan house window or crafted game tile. Inside, build a simple warm-ivory calendar from straight clay strips: rectangular page outline, two compact top tabs and a large centered checkmark. Add a narrow muted-sage hill stripe along the bottom and one restrained terracotta horizontal roof/cap strip near the top. Use premium 3D Soft Clay Neumorphism, matte polymer clay, controlled shallow depth, clean ambient occlusion, subtle tactile grain and a nearly front-facing camera. Keep it legible at 64px. Use a genuinely transparent background and no text, digits, extra scenery, organic stone medallion, topographic relief, gloss, metal, cyan, teal, purple, pink or Easter palette.

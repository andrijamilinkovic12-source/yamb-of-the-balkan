# Grandiozni vatromet

`blooms-master.png` is the original transparent artwork from the built-in image generator. Run `build.py` with Pillow and NumPy to rebuild `www/assets/effects/fireworks-blooms-v1/blooms.png`. Each column holds one burst, with its luminous body and hot embers on separate rows. The stage animates these components independently of the live falling sparks. Shared across all themes.

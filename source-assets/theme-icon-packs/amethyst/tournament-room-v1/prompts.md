# Kraljevski Ametist — Tournament PNG prompt set

Method: built-in imagegen, one original generation per semantic role. The approved champion cup was the material and silhouette reference for the finalist cup. The previously completed eight-entrant bracket remains part of the same set. Existing tournament medals already contain that champion cup and remain canonical. No other theme's icon was copied or recolored.

Common specification: 3D Soft Neomorphism in **Clay** direction. Heavy but calm sculpted amethyst arch with a few broad facets. Main colors: amethyst `#5A386A`, deep violet `#3C284B`, pale lilac `#E0CDE5`, restrained warm gold `#F2C879`. One strong symbol per icon, transparent background; no gemstones, crowns, jewelry, filigree, metallic shine, photorealism or decorative scenery.

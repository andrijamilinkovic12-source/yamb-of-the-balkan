# Neon Cyber — Tournament PNG prompt set

Method: built-in imagegen, one original generation per role. The approved Neon Cyber champion cup was used as material and palette reference; its exact distinctive silhouette guided the finalist silver cup. No icon was copied from or recolored from another theme.

Common specification: 3D Soft Neomorphism, **Smooth Rubber / Matte Plastic** direction, rounded rectangular segments with one clear notch, dark graphite `#193455` and `#080D18`, one controlled cyan edge `#56E5D2`, sparse functional magenta `#F08CE3`. A single strong symbol on a transparent square PNG, without multiple glowing contours, cybercity backgrounds, decorative effects, text or photorealism.

| Master | Subject |
| --- | --- |
| `finalist-silver-master-v1.png` | Slate-silver version of approved dark cup with the same segmented handles, cyan rim, magenta stem inset and tiered base. |
| `tab-info-master-v1.png` | Cyan information i in a notched graphite module. |
| `tab-bracket-master-v1.png` | Rounded dark knockout rails with exactly eight cyan entrant nodes (four left, four right) and one magenta final. The first six-entrant draft was rejected and replaced. |
| `tab-hall-of-fame-master-v1.png` | Three graphite honor columns with one large cyan star and a small magenta status inset. |
| `state-register-master-v1.png` | Notched dark admission module with a large cyan plus. |
| `state-unregister-master-v1.png` | Matching admission module with a large cyan minus. |
| `state-registration-locked-master-v1.png` | Closed segmented graphite lock with a cyan keyhole. |
| `state-start-master-v1.png` | Large cyan play triangle on a notched dark module. |
| `state-match-active-master-v1.png` | One frontal graphite die with exactly five cyan pips (four corners and center) and a tiny magenta play wedge. |
| `state-match-complete-master-v1.png` | Large cyan check in a compact notched status tile, legible at 15 CSS px. |

Each 1254 × 1254 RGBA master is normalized to a 256 × 256 RGBA runtime PNG with `scripts/build-tournament-room-pack.ps1 -Theme neon`. Paths, dimensions and SHA-256 hashes are in `manifest.json`. The existing three tournament medals already display the approved Neon Cyber champion cup and remain canonical.

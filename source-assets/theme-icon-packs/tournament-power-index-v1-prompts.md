# Turnir — Indeks snage, devet originalnih PNG ikona

Metod: built-in imagegen, jedan nezavisan generativni poziv za svaku temu. Svaki rezultat je zaseban RGBA master sa transparentnom spoljašnjom oblašću. Produkcioni PNG se centrira po vidljivoj alfi u kvadrat 256 × 256, bez pozadine.

Zajednički prompt: *Use case: stylized-concept. Asset type: tiny 12 CSS px Power Index PNG icon for the tournament bracket. Create one centered, compact, unmistakable energy symbol in 3D Soft Neomorphism, in the theme's declared direction and palette. It must read at 12 pixels. Genuinely transparent square cutout. No text, letters, dice, coins, stars, ornamental detail, frame, photorealism or copying/recoloring another theme's icon.*

# Plavi Okean — Tournament PNG prompt set

Method: built-in imagegen, one original generation per role. The approved Plavi Okean champion cup was the style and palette reference. It was also the silhouette reference for the silver finalist. No icon was copied from or recolored from another theme.

Common specification: 3D Soft Neomorphism, **Smooth Rubber / Matte Plastic** direction, broad arched forms and gently tapered edges, Aegean blue `#0E5A9B`, ivory `#FFF4E5`, deep blue `#173D5B`, restrained terracotta `#BD684A`. Single readable icon on transparent square PNG, without tourist motifs, repeated boats/waves, extra detail, text or photorealism.

The existing three tournament medals already show the approved blue champion cup and remain canonical.

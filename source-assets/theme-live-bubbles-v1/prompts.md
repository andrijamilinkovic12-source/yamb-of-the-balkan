# Magic bubble PNG prompt set

Generated with the built-in ImageGen tool, one independent transparent master per theme. Shared prompt: a single partly translucent bubble for a mobile game, 3D Soft Neomorphism, centered with generous transparent margin, readable at 20–88 CSS px, one soft internal reflection. No text, stars, extra bubbles, scenery, icons, jewelry, hard photorealistic glass, rainbow sheen or oversized glare.

`scripts/build-live-bubble-sprites.py` crops and scales every independent master to its 256 × 256 canonical PNG. The same themed sprite is shown at small, medium and large sizes during the effect and generates its Treasury preview and thumbnail. There is no recoloring from another theme.

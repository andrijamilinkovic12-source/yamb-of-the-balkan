# Solo record pictograms v1

Forty separate transparent PNG masters were generated with the built-in image generator: one call for each of the four roles in each of the ten themes. The runtime files are resized copies of their own master; no icon is recolored or copied across themes.

Shared requirements: 3D Soft Neomorphism, a restrained tactile object, isolated on transparency, a clear silhouette at mobile size, no text, medals, crowns, stars, confetti or ornate detail.

| Role | Visual meaning |
| --- | --- |
| Weekly | Seven-day calendar with seven marks and one weekly arc |
| Monthly | Month calendar with a compact multirow grid |
| All-time | Continuous infinity loop on a quiet base |
| Personal | One player profile with a rising personal score mark |

The category names remain localized, visually hidden text beside the images so screen readers can identify each role. The result status and Power Index value remain live text because they change with the confirmed match result.

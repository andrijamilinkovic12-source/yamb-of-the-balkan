# Pustinjsko staklo Pack

Kompletan vizuelni paket za temu Pustinjsko staklo. Aktivira se samo kroz `body.desert-theme`, odnosno kada je `localStorage.yamb_theme` podešen na `desert`.

## Šta paket pokriva

- originalna pustinjska pozadina: `www/assets/desert-neumorphic-bg-v1.png`
- desert glass badges & pills ikonice za modove, specijalne akcije i donji meni
- neumorfna tabla, kockice, polja, HUD i kontrolna zona bez promene dimenzija table
- kartice, fontovi, kontrast, inputi, modali, obaveštenja, chat, riznica, statistika, pravila i top lista
- splash, početni citat, čekanje protivnika i game-over ekran
- blage pustinjskie animacije uz podršku za reduced motion
- loading, prazna i error stanja
- proceduralni Desert Glass audio tonovi

## Pravila

1. Sve novo za ovu temu ide pod `body.desert-theme`.
2. Pozadina je pustinja; staklo se koristi samo na UI elementima.
3. Ne dirati globalne ikonice kao osnovu igre.
4. Ne menjati dimenzije table, soba/kartica i raspored bez posebne odluke.
5. Ostale teme ostaju izolovane i nepromenjene.
